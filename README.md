# Introduction
City Weather API retrieves weather data refreshed at an hourly interval by default.

## Tech Stack
This project is an Hono app in TypeScript build with Bun.
For the data storage we are using a Postgres 18 database

# How to run locally
To install dependencies:
```sh
bun install
```

To run:
```sh
bun run dev
```

open http://localhost:3000
